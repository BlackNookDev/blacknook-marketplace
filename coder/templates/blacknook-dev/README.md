# Blacknook Coder Developer Template
#
# Kurulum (Coder UI hazır olduktan sonra):
#   1. http://127.0.0.1:7080 üzerinde ilk admin hesabını oluşturun
#   2. API token alın (Account → Tokens) → CODER_API_TOKEN
#   3. Şablonu yükleyin:
#        brew install coder/coder/coder   # veya https://github.com/coder/coder/releases
#        coder login http://127.0.0.1:7080
#        coder templates push blacknook-dev -d ./coder/templates/blacknook-dev --yes
#   4. Template ID'yi kopyalayıp CODER_TEMPLATE_ID olarak ayarlayın
#   5. Marketplace app'i yeniden başlatın (env güncellemesi)
#
# Kaynaklar: 2 vCPU · 2 GiB RAM · Node 22 LTS · Python 3 · Git · code-server
